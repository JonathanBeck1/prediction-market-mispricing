# Code of Conduct

This project welcomes direct technical criticism, careful analysis, and evidence-backed disagreement.

Please keep discussions focused on the work:

- Be respectful of contributors and users.
- Critique ideas, data, code, and claims rather than people.
- Do not post private credentials, trading account details, phone numbers, or other sensitive information.
- Do not use issues, pull requests, or discussions to solicit financial advice or promote trades.
- Respect the project invariant: this software is advisory only and must not place orders automatically.

Maintainers may edit or remove comments, issues, or pull requests that are abusive, spammy, unsafe, or unrelated to the project.
